# VeilCheck 怎样处理你的文件

## 简单说

文件留在你的电脑上。浏览器把文件交给运行在 `127.0.0.1` 的本地页面处理，识别结果和遮挡框只保存在当前页面内存中。刷新或关闭页面后，这些状态不会被 VeilCheck 保存到账号或服务器。

## 会读取什么

- 你主动选择、拖入或粘贴的图片与 PDF
- 你输入到文本检查区的文字
- 你填写的自定义敏感字段

## 会生成什么

- 重新编码的 PNG 图片
- 逐页栅格化后重新生成的 PDF
- 不包含原始敏感值、图片内容和位置坐标的 JSON 检查报告

原文件不会被覆盖。

## 不会主动做什么

- 不创建账号
- 不上传文件或 OCR 内容
- 不记录使用次数
- 不加载远程 OCR、字体、PDF 解析器或统计脚本

## 浏览器能力

二维码自动检测可能调用浏览器内置的 `BarcodeDetector`，这仍是本地浏览器能力。不同浏览器支持程度不同，不支持时应用会提示使用手动画框。

## 风险仍然存在

本地处理只能减少“文件被第三方服务看到”的风险，不能保证检测结果完整。自动识别可能看错字，也可能完全没看到某个区域。安全副本必须由人再看一遍；高敏信息应使用实心遮挡或隐私标签。
